# NBA Team Performance Analysis

### Overview
- Analyze NBA teams performance over the past decade (2015-2016 season -> 2025-2026 season) to answers various questions
    - How does the teams recent performance (last 10 games) compared to their average performance over the past year
    - In what areas (offensive plays, defensive plays) does the teams excel at?
    - How does each player in a team contribute (Points, Assits, Rebounds) to the teams performance?

### Data Sources
- NBA Stats API [Link](https://github.com/swar/nba_api)
    - An API client package to easily access the APIs of NBA.com
